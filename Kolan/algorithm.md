## Техническое задание (уточнённое по примеру расчёта)

### Назначение
Программа назначения участков ремонта дорожного покрытия по данным измерения глубины колеи.

### Входные данные
1. **Файл с метровыми измерениями**: каждая строка = 1 метр пути. Столбцы: километр, метр, глубина левой колеи (мм), глубина правой колеи (мм). В примере — 5783 строки (км 1 м 1 ... км 6 м 799).
2. **Настраиваемые параметры**:
   - **Допустимый предел** средней глубины колеи (в примере: **20 мм**)
   - **Размер окна осреднения** — **10 метров** (текущий + 9 вперёд). В примере Excel была ошибка (9 вместо 10), дедушка подтвердил: правильно 10.
   - **Минимальная длина ремонтной карты** (в примере: **100 м**)
   - **Минимальное расстояние между картами** для решения о НЕ-объединении (в примере: **100 м**; в тексте алгоритма упоминается 200 м как другой пример — это просто настраиваемый параметр)

### Алгоритм (подтверждён примером расчёта)

#### Шаг 1. Скользящее среднее
Для каждого метра вычислить среднее значение глубины колеи (левой и правой **отдельно**) на окне из **10 значений** вперёд: `AVG(текущий, +1, +2, ..., +9)`. На последних метрах окно сужается до оставшихся значений (на предпоследнем метре — 2 значения, на последнем — 1).

#### Шаг 2. Выявление неудовлетворительных метров
Метр считается **неудовлетворительным**, если осреднённое значение **хотя бы одной** колеи (левой **ИЛИ** правой) **>=** допустимого предела.
- *Подтверждено примером*: 948 жёлтых строк, из них 593 — только левая >= 20, 12 — только правая >= 20, 343 — обе.

#### Шаг 3. Вычисление разрывов
Для каждого неудовлетворительного метра (отсортированных по километражу) вычислить расстояние **до следующего** неудовлетворительного метра: `P = I(следующий) - I(текущий)`.

#### Шаг 4. Объединение в карты
Все неудовлетворительные метры, между которыми разрыв `P < порог объединения` (100 м в примере), объединяются в одну ремонтную карту. Карта простирается от первого до последнего неудовлетворительного метра в группе.

*Из примера — три группы карт:*

| Группа | Десятиметровки | Диапазон | Жёлтых строк |
|--------|---------------|----------|---------------|
| 1 | 3+899 ... 4+035 | 131 м | 96 |
| 2 | 4+235 ... 5+346 | 1096 м | 845 |
| 3 | 5+542 ... 5+548 | 7 строк (16 м покрытия) | 7 |

Между группами 1-2 разрыв 200 м (>= 100, не объединяем), между 2-3 — 196 м (>= 100, не объединяем).

#### Шаг 5. Проверка минимальной длины и удлинение
Если длина карты < минимальной (100 м):
1. Вычислить длину покрытия: `(последний_адрес - первый_адрес + размер_окна)`. Пример: 548 - 542 + 10 = **16 м**.
2. Вычислить недостаток: `100 - 16 = 84 м`.
3. Расширить область поиска: `начало - 84` и `конец + 84` (пример: 5+458 ... 5+642 = 185 м).
4. В расширенной области с каждого метра вычислить скользящее среднее по **метровым** (не осреднённым) значениям на окне = минимальная длина карты. В примере: `AVERAGE(101 значение)` — **окно 101 метр** (формула `AVERAGE(AC21:AC121)`).
5. Выбрать позицию окна по критерию: **наибольшее значение худшей (глубочайшей) колеи**. Левую и правую колею НЕ усреднять между собой — односторонняя глубокая колея опаснее двусторонней (при заполнении водой создаёт разворачивающий момент). Для каждой позиции окна берём `MAX(среднее_левой, среднее_правой)` и выбираем позицию, где этот максимум наибольший. В примере: максимум левой колеи = 18.52 мм при адресе **5+501** (начало карты 5+501, конец 5+601).

#### Шаг 6. Уточнение адресов по метровым значениям
**Только для карт, которые НЕ были удлинены** (шаг 5). Для удлинённых карт адреса берутся как есть из скользящего окна.
- Каждая «десятиметровка» на позиции X покрывает метры X ... X+9
- Общий диапазон метров карты: от первой десятиметровки до (последняя + 9)
- **Начало карты** = первый метр в этом диапазоне, где фактическое значение >= порога
- **Конец карты** = последний метр в этом диапазоне, где фактическое значение >= порога

*Пример карты 1:*
- Десятиметровки: 3+899 ... 4+035 -> метры: 3+899 ... 4+044
- Первый метр >= 20 мм: **3+903** (левая = 20.48)
- Последний метр >= 20 мм: **4+039** (левая = 20.44)
- Итого: карта **3+903 ... 4+039**

#### Шаг 7. Итоговая таблица
Для каждой карты:
- Адрес начала (км+м) и конца (км+м)
- Протяженность (м)
- Средние значения глубины левой и правой колеи
- Максимальные значения глубины левой и правой колеи

## Уточнения от дедушки (получены 2026-03-27)

1. **Окно осреднения = 10 метров** (текущий + 9 вперёд). В примере Excel была ошибка — формула захватывала 9 значений вместо 10. Дедушка подтвердил: всегда усреднял по 10 м.

2. **Критерий выбора стометровки при удлинении: наибольшая из двух колей** (не сумма). Односторонняя глубокая колея опаснее двусторонней — при заполнении водой создаёт разворачивающий момент. Поэтому левую и правую колею между собой усреднять нельзя. Берём `MAX(среднее_левой, среднее_правой)` для каждой позиции окна и выбираем позицию с наибольшим значением.

3. **Уточнение адресов удлинённых карт не делается.** Адреса берутся как есть из скользящего окна.
